# Misi-portfolio

Interactive 3D medical portfolio for **Mismak Mulu, Anesthesiologist** (Mekelle University / Ayder Comprehensive Specialized Hospital).

## Features
- **God-Level Anesthesia Navbar**: Floating glass capsule, live ECG vital monitor (heart rate, BIS score, SpO₂), circadian dark/light mode toggle.
- **Hero Showcase**: Full-screen portrait with high-contrast typography, stats, and smooth navigation.
- **Clinical Expertise**: 6 core disciplines (Obstetric, Trauma RSI, Nerve Blocks, General/TIVA, Difficult Airway, Pediatric).
- **Formal Contact**: Institutional affiliations and inquiry form.
- **Tech Stack**: Next.js 16 (Turbopack), TypeScript, Tailwind CSS, Framer Motion, next-themes, Lucide Icons.

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
